## 아직 안 된 것 / 다음 챗에서 할 것

### A. 매일 자동 갱신 (오늘 결정 대기 중)
PC에 `.git`이 없어서 자동 push가 안 된다. 두 길 중 선택 필요:
- **A-1. PC를 저장소에 연결** — PC 루트에서 git init + remote 연결.
  단 PC는 평면 구조, 저장소는 code/data 구조라 **구조를 맞춰야** 함.
- **A-2. 저장소 구조를 PC 평면 구조에 맞춤** — 저장소를 평면으로 재배치하고
  PC를 거기에 연결. (교수님의 code/data 분리 원칙과 상충)
- 어느 쪽이든 그 다음 `run_daily.ps1` 끝에 "manifest 재생성 → git add/commit/push" 추가.
  (지금 ps1엔 이 3줄이 **없다**.)

### B. 반려 기록 → 기획실 루프 (구멍 메우기)
- ① 반려/승인 결정을 **파일로 저장**: `state/decisions.jsonl` (사람이 복사→붙여넣기, 또는 반자동)
- ② 기획실이 그걸 **읽게**: pipeline_prompt 0단계에 "최근 반려 사유를 읽고 피하라" 추가
- ③ 측정 루프: 반려 사유를 지표화(무엇이 자주 반려되나) → 대시보드에 표시

### C. 교수·동료 피드백 남은 항목
- (2) 피드백실 이후 사람 접근 → B와 연결
- (3) 피드백 측정 루프를 대시보드 지표로 (목적→지표→관찰→해석→수정→재확인)
- (4) 사람 부재 가드레일 (승인 안 하고 며칠 지나면 어떻게 재개할지)
